OPENWITHLOVE — B2 SOFT MEMORIES

A reusable Birthday template with a soft scrapbook / memory-book aesthetic.

7-stage flow:
1. Opening
2. Birthday
3. Photos
4. Memories
5. Personal Letter
6. Special Surprise
7. Final Message

CUSTOMIZE:
- Edit config.js for name, text, captions, memories, letter, surprise and final message.
- Replace photos/photo1.svg ... photo5.svg with customer photos. If changing extensions, update the src values in config.js.
- Add the chosen song as music/birthday.mp3.
- Keep index.html, config.js, photos/ and music/ together.

For GitHub Pages, upload the CONTENTS of this folder so index.html is at repository root.

Open a moment. Feel the love. ❤️
